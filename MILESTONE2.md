# Milestone 2 - Run and Validation Commands

## TypeScript Logic Module Location

`components/milestone2`

## Install

```bash
cd components/milestone2
npm install
```

## Validate TypeScript (required command)

```bash
npx tsc --noEmit
```

## Build

```bash
npm run build
```

## Manual Test UI (Tailwind)

```bash
npx --yes serve . -l 3000
```

Then open:

- `http://127.0.0.1:3000/components/milestone2/index.html` (Milestone 2 test page)
- `http://127.0.0.1:3000/project-shell.html` (global shell with Milestone 1, Milestone 2, Milestone 3 placeholder, and Full Project views)
